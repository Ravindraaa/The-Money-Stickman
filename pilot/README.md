# Five-second visual pilot

This is a separate pilot workflow so the existing first Short remains untouched.

- Character: consistent porcelain-white 3D stickman with expressive face.
- Environment: cinematic midnight office with city window, neon accents, desk, monitor and floating money props.
- Voice: Kokoro American English male preset, energetic speed.
- Sync: mouth scale is keyed from the generated narration's audio envelope.
- Camera: animated push-in/reframe.
- Music: original synthesized electronic bed with ducked level and whoosh accents.

Run the **Render The Money Stickman Pilot** workflow manually from GitHub Actions. Review the exported MP4 before deciding whether to lock this look for full episodes.

This is a technical style pilot, not a finished episode or a claim of perfect phoneme-level lip sync. The mouth follows the voice amplitude envelope; true phoneme/viseme animation is a later quality upgrade.
