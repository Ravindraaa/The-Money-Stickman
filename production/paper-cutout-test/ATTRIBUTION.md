# Paper-cutout and animation code attribution

This folder vendors reusable code from [illodev/drawn-by-code](https://github.com/illodev/drawn-by-code), Copyright (c) 2026 illodev, under the MIT License:

- `vendor/core.js` — deterministic motion helpers, easing, sprite caching, camera and layers.
- `vendor/transitions.js` — reusable camera/object-led transition primitives.
- `vendor/paper.js` — torn cutouts, paper fibres, marker texture, grain and geometry.
- `vendor/kit.js` — paper labels, sheets, typography and reusable cutout props.
- `vendor/detail.js` — detailed hand poses, fabric and printed-material details.
