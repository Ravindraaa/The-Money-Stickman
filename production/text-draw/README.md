# Text + Draw Motion Pilot

A fresh 12-second, character-free visual test.

- No stickman, people, character rigs or stock footage.
- Kinetic typography plus original SVG/CSS vector drawings only.
- Three beats: paycheck deposit, bills subtracting, and $20 automatic savings.
- Fast micro-movements and two scene changes.
- Example budget values are illustrative.
- Visual-only prototype; it is not a finished narrated Short. Voiceover must be matched phrase-by-phrase before a full episode is produced.

Render with the **Render Text + Draw Motion Pilot** GitHub Actions workflow. Inspect the actual MP4 before approving or extending the style.
