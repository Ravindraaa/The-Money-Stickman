# Short 13 — Your First $1,000 Changes Everything

A 40-second, 9:16 finance short prototype for the US audience. The composition is rendered automatically by GitHub Actions on `engine-v2-foundation`.

- Storyboard: eight scenes, with a recurring black hoodie / gold dollar-sign character.
- Motion: GSAP camera-like pushes, prop reveals, transitions and scene-specific movement.
- Voice: Chatterbox US English generated in CI, then muxed into the MP4.
- No YouTube upload: the workflow only creates a review artifact.
- Financial arithmetic: $25 × 52 = $1,300. No unsupported survey statistics.

The uploaded Faceless Shorts skill informed the faster scene pacing, visual-first storytelling and recurring character approach. This is an adaptation to the existing HyperFrames + GitHub Actions pipeline, not a full installation of every bundled skill dependency.
